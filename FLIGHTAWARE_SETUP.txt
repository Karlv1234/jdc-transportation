VERCEL ENVIRONMENT VARIABLE
Name:
FLIGHTAWARE_API_KEY

Value:
Your FlightAware AeroAPI key

Add it under:
Vercel Project > Settings > Environment Variables

Enable it for:
Production
Preview
Development

After adding the key, redeploy the project.

LOCAL DEVELOPMENT
Create or edit this root-level file:
.env.local

Add:
FLIGHTAWARE_API_KEY=your_key_here

Do not use NEXT_PUBLIC_ and do not commit the API key.
